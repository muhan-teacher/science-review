# 무한쌤의 통합과학 ∞도전 — 복습 프로그램
통합과학 Ⅰ-1-02 생물의 진화 ~ 03 생물다양성과 보전 단원의 웹 복습 프로그램입니다.
## 구성
- 개념 정리: 변이 → 자연선택 → 진화 (딱정벌레·항생제 내성·갈라파고스 핀치 사례, 이쑤시개 모의실험)
- 생물다양성: 유전적/종/생태계 다양성 비교표, 바나나·메뚜기·갯벌 사례, 가치와 보전 방법
- 복습 퀴즈: 기본 10문항 / 심화 10문항 / 전체 도전 20문항, 즉시 해설·오답 노트·틀린 문제 다시 풀기
## 사용 방법
`index.html` 파일 하나로 동작하며 별도 설치가 필요 없습니다. GitHub Pages로 배포하여 학생들에게 링크로 공유할 수 있습니다.
